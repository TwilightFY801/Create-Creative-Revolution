# 机械动力：创意革命 · Create: Creative Revolution

面向 **Minecraft 1.21.1 / NeoForge** 的《机械动力》（Create）附属模组。

> **Minecraft:CPC 是本模组的前身。**
> 早期那一版以「党的工具」为主题的内容，现已作为本模组的**旧内容分区**保留下来（见下方分区一）。

模组 id 为 `dangtools`。游戏内经创造模式物品栏分为 **两个分区**（类似《机械动力：航空学》的分区横幅）。

---

## 平台与前置

| 项 | 值 |
| --- | --- |

| 前置 | **机械动力 Create**、**Create 航空学 Aeronautics**（含 Offroad / Sable / Simulated 等子模块） |

## 内容（两个分区）

### 分区一：革命：中国共产党
> ⚠️ **此为旧内容，今后永远不再更新。** 仅保留以下 5 件：

| 物品 | 作用 |
| --- | --- |
| **锤子** | 挖掘更快；对着矿石右键可直接产出掉落物，且掉落翻倍 |
| **镰刀** | 收割农作物时掉落物翻倍 |
| **来自中国伟大的党** | 攻击力大幅加强，并继承锤子与镰刀的能力 |
| **国旗** | 范围内提供满级信标增益 |
| **飞行执照** | 副手=无限不死图腾；胸甲=保护+荆棘+可滑翔且隐形 |

### 分区二：机械动力：创意革命
> ✅ **此分区会持续更新。** 目前大致包含：

**物品**
- **质量探测器** —— 探测方块的质量
- **高抓地轮胎** —— 小型 / 普通 / 大型 / 巨型 四种尺寸
- **漂移轮胎** —— 小型 / 普通 / 大型 / 巨型 四种尺寸

**方块**
- **高级马达** —— 类似创造马达，但应力数值大幅提高，且可在生存模式合成
- **重力方块** —— 可调节「重量 / 重力」
- **双轮悬架** —— 装一个轮胎即可在正前方延展出第二个车轮，两轮一起转
- **微调配重块** —— 用于精细配重
- **照明拉杆** —— 载具灯光总控
- **大灯 / 刹车灯 / 左转向灯 / 右转向灯 / 车内照明灯** —— 一整套载具灯光
- **灯光按键设置** —— 可自定义「前进 / 后退 / 左转 / 右转」对应的灯光行为

## ⬇️ 下载

最新版本请到本仓库右侧的 **Releases** 下载 jar 文件。

> 本仓库**只放源码**，不附带 jar，也不附带第三方依赖。

## 🔧 从源码构建

需要 **JDK 21** 与 Gradle（仓库自带 wrapper）。

1. 把第三方**编译期依赖 jar** 放进 `libs/`（本仓库不分发，清单见 [`libs/README.md`](libs/README.md)）。
2. 构建：

```bash
./gradlew build
```

产物在 `build/libs/` 下。
